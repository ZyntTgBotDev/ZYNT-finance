# ZYNT FINANCE — Local PWA

Автономное PWA-приложение для личного учёта доходов и расходов. Сервер, аккаунты, API и облачная база не используются. Данные хранятся в IndexedDB браузера на текущем устройстве.

## Публикация через GitHub Pages
1. Создайте репозиторий GitHub и загрузите содержимое этой папки в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
4. Дождитесь публикации. Откройте HTTPS-ссылку на iPhone или Android.
5. iPhone: Safari → Поделиться → На экран «Домой». Android: Chrome → меню → Установить приложение.

## Локальные данные и перенос
Все доходы, расходы, профиль, задания, опыт и тема сохраняются в IndexedDB этого браузера. Интернет нужен для первой загрузки и получения обновлений, после кеширования приложение работает офлайн. Для переноса используйте Профиль → Экспорт / Импорт.

Очистка данных сайта, удаление браузерного хранилища или удаление приложения может удалить локальные записи. Делайте резервные копии. Данные не синхронизируются между устройствами.

## Код первого запуска
Код `21122024` реализован как локальный экран-приглашение. Это не криптографическая защита: поскольку приложение целиком клиентское и открытый код загружается в браузер, технически знающий пользователь может обойти эту проверку. Не используйте приложение для хранения секретов или банковских учётных данных.

## Игровой опыт
XP начисляется только за отметку выполнения заданий. Запись доходов и расходов не даёт XP. В текущей версии награды заданий заданы в XP напрямую; принцип «1 ₽ награды = 1 XP» поясняет конверсию игровых наград, а не реальные выплаты.
